# DEVCONF 2026

A responsive static landing page for a fictional developer conference, built as an HTML and CSS web-development assignment.

## Live site

[View DEVCONF 2026](https://nafus08.github.io/nafus-A01/)

## Tech stack

- HTML5
- CSS3
- GitHub Pages

## Features

- Conference hero section with registration calls to action
- Speaker cards and event information sections
- Pricing cards for conference passes
- Navigation links to page sections
- Custom logos, speaker imagery, and responsive styling

## Run locally

```bash
git clone https://github.com/nafus08/nafus-A01.git
cd nafus-A01
```

Open `index.html` in a browser. No build step or package installation is required.
